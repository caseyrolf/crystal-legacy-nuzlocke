# Crystal Legacy Nuzlocke Log

Open `index.html` in a modern browser. No installation or server is required.

Enter a password of at least three characters to create or reopen a playthrough. The password is used only to choose that playthrough's local browser storage key; data is never uploaded. Use the same browser and password to return to a run.

The encounter catalog is extracted from the supplied `Crystal Legacy Encounters.docx`. It includes the full morning, day, night, water, and fishing pools for every route, cave, and town documented there.

Use **Clear this entry** if a selection was entered in error. Clearing an earlier area also makes that Pokémon selectable again in later areas.
